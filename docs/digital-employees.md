# 数字员工产品纳入展示中心

更新时间与价格调研：2026-09-06。

## 产品来源与范围

依据用户提供的四张产品图，新增三条数字员工产品线。岗位名称来自附件，页面中的问题、输入、输出、示例工作流为帮助用户理解的编辑整理，不是对现有后端能力或上线状态的测试结论。

- 企业版：16 个岗位，覆盖人力、财务、法务、销售、内容、合同、客服、采购、行政、会议、项目、招投标、知识、经营、IT 与培训。
- 政府版：6 个岗位，政策专家、公文助手、法律顾问、会议秘书、智慧导办（虚拟政务人）、行业研究员。
- 行业版：7 个行业 / 21 个岗位场景，医疗、教育、文旅、政务、农业、金融、交通。

本产品的行业版包含“金融”，并不等同原有12个行业智能体家族。两类目录独立，未擅自调整原有行业智能体数量、名称或上线状态。

数字员工未获提供实际试用地址与上线状态，因此统一显示“产品方案 · 按需交付”，没有设置虚假已上线徽标或试用入口。平台五层结构和六步构建流程按原图重组为网页文字。

原图保存在 assets/digital-employees/ 下：architecture.png、enterprise.png、government.png、industry.png。各详情页底部可展开并打开高清原图。

## 官方竞品价格依据

1. [扣子企业版计费规则](https://docs.coze.cn/coze_pro_enterprise_plan)：2026-07-14 起现行刊例价，企业标准版套餐490元/月，至少5席位，每席位29元/月及69元/月积分，最低 490 + 5×(29+69) = 980元/月；旗舰版最低8980元/月。平台成员与数字岗位并非相同计量单位。
2. [飞书 AI 官方方案](https://www.feishu.cn/service/ai)：搜索索引中的官网公开方案基础版9900元/年、18万点AI额度，不限席位；企业版9.9万元/年、200万点AI额度。年度价格不能写成月付价格。页面动态加载，检索记录为官网索引文本，订购前应再核当前界面。
3. [影刀 RPA 官方网站](https://www.yingdao.com/)：企业版按需求咨询方案、服务与报价，未使用未经核实的固定价格或宣传性能数据。

扣子、飞书是能力平台，影刀是自动化平台，与数字员工的岗位、知识、系统连接和实施内容不同。不能用上述报价直接断言市场均价或同等能力折扣，也没有找到与本项目三条产品线完整交付范围一致的公开成交价。

## 本次建议价格与费用边界

| 方案 | 建议起价 | 包含范围 |
| --- | --- | --- |
| 企业云端入门 | 499元/月，全年5988元 | 3个岗位配置、10名使用成员、1条标准流程模板（自助配置）、1000次模型调用/月、5GB知识空间 |
| 企业云端新增岗位 | 99元/岗位/月 | 仅增加角色配置，不增加成员、用量或定制对接 |
| 企业本地标准部署 | 19800元/套起 | 3个岗位、2条标准流程、标准授权、基础部署、培训、首年基础维护、1个已有标准接口的配置调试 |
| 政府本地标准部署 | 29800元/套起 | 3个岗位、2条标准流程、基础权限与日志配置，以及上述标准交付服务 |
| 行业单场景交付 | 39800元/场景起 | 1个明确行业场景、3个岗位、2条标准流程，以及上述标准交付服务；非7行业/21岗位全包 |
| 政府/行业专属云、已有平台扩展 | 按差异评估 | 先确认数据、已有资源与适配范围，再出报价 |

企业云端定位比竞品平台更小的标准岗位试点，因此建议499元起；并非承诺与980元平台套餐具有相同权益。本地三个价位由标准化配置与行业实施深度区分，没有已验证成本单，不属于网络查到的市场成交价。

云端调用预算的计算口径：每次模型调用输入≤8K tokens、总生成≤2K tokens（含思考），1000次最多约1000万tokens/月，多步任务消耗多次；语音、视频、图片、检索等外部能力另算。正式销售前按所选模型的输入/输出单价、存储、并行执行、RPA授权、运维和支持工时核算，不承诺利润率。用户用量不足时暂停或确认加购，不自动超额扣费。

私有化标准接口指已有连接器且客户已提供授权接口的基本配置，排除定制连接器和复杂业务适配。RPA运行器、桌面适配、复杂权限、审批流、数字人形象及实时音视频、硬件、第三方模型调用、现场服务与历史数据治理需另行评估。特别说明：智慧导办（虚拟政务人）岗位不默认包含实时数字人视频服务。

各部署方案互为选项，不将云端、本地软件、一体机整套平台价格重复相加。已有平台复用已授权能力，仅对新增范围报价。此前智立方Lite/Pro的39800/59800元方案不默认包含新增数字员工实施，需按设备已含授权与新增交付范围拆分核价。

岗位数量、成员数量和并发是三个不同概念。原先Lite 1–2人、Pro 2–4人的同时回答估算仅适用于明确的短文本模型场景。数字员工多步任务、RPA和工具执行共享算力，不按岗位个数叠加容量，须用实际工作流压测。正式报价中需约定税费、授权、保修、次年维护与验收标准。
